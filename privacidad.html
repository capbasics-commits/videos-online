Política de privacidad de Videos Online

Última actualización: 20 de octubre de 2026

Qué es

Videos Online es una herramienta privada de uso personal. Funciona en el ordenador de su autor y sirve para subir vídeos cortos (Shorts) de fútbol a su propio canal de YouTube, Mundo Fultbol Actualidad, y leer las estadísticas de ese canal. Solo la usa el dueño del canal: no hay otros usuarios ni registro.

Qué datos de Google usa

Usa la API de YouTube Data v3 y la API de YouTube Analytics con estos permisos:

  • youtube.force-ssl: subir vídeos al canal del autor y gestionarlos.
  • yt-analytics.readonly: leer las estadísticas de ese mismo canal.

Solo accede a la cuenta y al canal del propio autor.

Dónde se guarda

El permiso de Google (token de acceso) se guarda solo en el ordenador del autor. Esta web no usa cookies ni analítica.

Con quién se comparte

Con nadie. No se venden, no se comparten y no se transfieren datos a terceros.

Uso Limitado

El uso que Videos Online hace de la información recibida de las API de Google cumple la Google API Services User Data Policy, incluidos los requisitos de Uso Limitado.

Cómo retirar el acceso

Se puede retirar el permiso en cualquier momento desde https://myaccount.google.com/permissions.

Summary in English

Videos Online is a private, personal-use tool that runs on its author's computer. It uploads short football videos to the author's own YouTube channel and reads that channel's statistics, using the YouTube Data API v3 and YouTube Analytics API with the youtube.force-ssl and yt-analytics.readonly scopes. Only the channel owner uses it; there are no other users, no sign-up, no cookies and no web analytics.

The Google authorization is stored only on the author's computer. No data is sold, shared or transferred to third parties.

Videos Online's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at https://myaccount.google.com/permissions. Contact: jrosero0305x@gmail.com. Last updated: October 20, 2026.
